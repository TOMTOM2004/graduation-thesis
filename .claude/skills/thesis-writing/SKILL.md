# 卒業論文 執筆・推敲スキル

このスキルの目的は2つ。(1) 論文執筆が初めての書き手が、審査に耐える論証を書けるようにする。(2) この論文固有の地雷（stale 数値・撤回済み主張・クレーム階層の踏み外し）を機械的に踏まないようにする。(2) は 2026-07-06 の全体監査（DEC-019/021）で実際に起きた事故の再発防止であり、譲れない規律として扱う。

## 0. 書き始める前に必ず読むもの（SSOT）

| 何を | どこ | 理由 |
|---|---|---|
| 研究質問（主問・副問1-3） | `docs/overview.md` | RQ の正はここ。paper 側で言い換えて意味を変えない |
| クレーム階層（Tier1/Tier2） | `docs/decision-log.md` DEC-017・DEC-021・DEC-023（暦年正準値） | 何を断定してよく、何を断定してはいけないかの正 |
| 識別の到達点と限界 | `docs/research-design.md`「識別の到達点と限界」＋ DEC-024（GPSS share外生枠・1段落言語化） | 識別まわりの文言はこの節の言い回しに揃える |
| 章割り | `paper/outline.md` | 執筆単位への割り付け |
| 意思決定の経緯 | `docs/decision-log.md`（DEC-001〜022） | 「なぜこの設計か」を本文で説明するときの根拠 |

## 1. 執筆時の視点（書き方の原則）

### 1.1 論証の最小単位はパラグラフ

- **1段落 = 1主張**。段落の先頭文（トピックセンテンス）だけを拾い読みして論旨が追える状態を目指す。書き終えたら先頭文だけ縦に読んで確認する。
- 段落内の順序は「主張 → 根拠（数値・先行研究）→ 解釈・限界」。根拠を先に並べて主張を最後に置く帰納スタイルは、審査者が「で、何が言いたいのか」を見失うので原則使わない。
- 1文は短く。主語を省略しない（日本語論文で最も多い曖昧さの源）。接続は「したがって・一方・ただし」など論理関係が一意な語で明示する。

### 1.2 章の役割を守る

- **序論**: 問い・動機・貢献の予告。結果の数値はハイライトのみ（詳細は結果章）。
- **先行研究**: 列挙ではなく**位置づけ**。「A は X を示した。B は Y。しかし Z（＝本研究の空白）は未検討」という構造で、必ず空白①②③（`docs/contribution.md`）への着地で終える。
- **方法**: 再現可能性が基準。読者が同じデータ・同じ手順で追試できる粒度で書く（README の再現手順と整合させる）。
- **結果**: 事実の記述に徹する。解釈は考察へ。図表は本文で必ず参照し、「図 N は〜を示す」で読み方を与える。
- **考察**: 結果の解釈・先行研究との対比・限界。ここで初めて「意味」を語ってよい。
- 限界は隠さず**構造化して**書く。この論文では限界の提示自体が貢献③（識別限界の方法論的提示）なので、限界節は「弱点の告白」ではなく「方法論的成果の章」として書く。

### 1.4 数値の規律（DEC-021 の教訓）

- **論文に書いてよい数値は「repo に再現経路がある値」だけ**。記憶・過去スライド・古い doc からの転記は禁止。迷ったら §3 の golden 表を見る。
- 数値を本文に入れるたびに、下書き段階では行末コメント（`<!-- 出所: trade_loss_total.csv -->` など）で出所を残す。最終稿で消す。
- 「約」「およそ」の丸めは一貫させる（35,275億→「約35兆円」、0.4253→「0.425」。同じ量を章によって違う丸めで書かない）。

### 1.5 引用の規律（DEC-019 の教訓）

- 先行研究の**数値**を引くときは、文献メモ（`docs/literature/papers/`）ではなく**原典**で該当箇所を確認してから書く。かつて「齊藤2022 = GNI比4.6%」という原典に存在しない数値が3ファイルに伝播した（AI 混入・DEC-019 で排除）。文献メモは索引であって出典ではない。
- 引用形式は「著者（年）」で統一。孫引きをする場合は「（A, B より引用）」と明示。

## 2. 推敲チェックリスト（章を書き終えるたび・提出前に全章）

自己レビューは以下の7視点を**別々のパスで**回す（1回の読み直しで全部見ようとすると全部漏れる）。

1. **数値突合**: 本文の全数値を grep で列挙し、§3 golden 表 or 生成 CSV と突合。一致しないものは書き直すか、出所を確認して golden 表を更新（勝手に本文側を「正しそうな値」に直さない）。
2. **撤回済み主張の混入**: 次のパターンを grep して、ヒットしたら文脈を確認する:
   `1.42|0.431|p=0.002|9.744|34.6兆|101.6|123.8|4.6%|213〜286|プラセボ.*非有意|分離したうえで|清浄に識別|0.425|p=0.047|2.14|1.26pp|10.00pp|識別に類例`
   （これらは全て撤回済み・DEC-019/021、または年度→暦年統一（DEC-023）で退役した旧年度値・DEC-024 で禁止した表現。歴史的経緯・provenance 注記として言及する場合は「旧年度ベースでは〜」「当初の推計では〜だったが」と明示的に書く）
3. **主張の強さ校正**: 各段落の述語動詞を §1.3 の表と照合。「示した」「実証した」が Tier 2 の内容に付いていたら降格する。
4. **章間一貫性**: RQ（序論）→ 方法 → 結果 → 考察 → 結論のあいだで、①同じ量が同じ値か ②結論が RQ に答えているか ③方法に書いていない手順の結果が突然出ていないか、をトレースする。
5. **引用実在**: 引用した文献が `docs/literature/INDEX.md` にあるか、数値引用は原典確認済みか。
6. **図表整合**: 全図表が本文から参照されているか。図表の数値・キャプションが本文と一致するか。図は再生成可能か（生成スクリプトが repo にあるか）。
7. **読者テスト**: 指導教員・審査者の視点で「この段落に『なぜ？』『本当に？』と赤を入れるならどこか」を各節1つ以上探す。見つからない節は読み込みが浅い。

チェック 1・2 は機械的にやる（目視でやらない）:

```bash
# 数値の列挙（paper/ 配下）
grep -oE '[0-9]+\.[0-9]+(pp|%|兆)?' paper/<章ファイル>.md | sort | uniq -c
# 撤回済み・旧年度パターンの検出
grep -nE '1\.42|0\.431|p=0\.002|9\.744|34\.6兆|101\.6|123\.8|4\.6%|プラセボ.*非有意|0\.425|p=0\.047|2\.14|10\.00pp|識別に類例' paper/*.md
```

## 4. 執筆の進め方（1章あたりの手順）

1. `paper/outline.md` で章の割り付けと「状態」を確認
2. 骨子（トピックセンテンスだけの箇条書き）を先に書き、ユーザーと合意
3. 本文ドラフト（数値は `<!-- 出所 -->` コメント付き）
4. §2 の7視点セルフレビュー（1・2 は grep で機械実行）
5. ユーザーレビュー → 反映 → outline.md の状態を更新・コミット
6. 数値を新規に導出した場合は DEC 起票を検討（`docs/decision-log.md`）

## 5. 発表資料との関係（凍結方針）

- 発表済みスライド（seminar1）は**提示記録として凍結**。旧値（34.6兆・GNI比4.6% 等）が残っているが修正しない。論文には持ち込まない。
- 未発表スライド（seminar2〜4）は DEC-023（暦年）反映済み。論文とスライドで数値が食い違ったら、正は §3 の golden 表（＝DEC-023 準拠）。
