# 卒業論文プロジェクト — Claude Code ルール

## プロジェクト概要

外的要因による輸入価格ショックが日本の実質所得を海外に流出させる構造を定量化し、財の特性と所得階層の異質性を加味して家計消費への影響を分解し、シミュレーションモデルによる政策評価を行う学部卒業論文。
実証経済学・応用計量経済学に属する構造分析とシミュレーションを組み合わせた研究。

**現在のフェーズ: Phase 1〜3（分析）完了 → 論文執筆 + ゼミ発表スライド作成**

---

## ドキュメント構成

- `docs/` — 卒論の研究計画・設計ドキュメント（INDEX.md がエントリーポイント）
- `docs/DESIGN.md` — スライド作成のビジュアル・構造ルール（後述）
- `src/` — 分析コード（実装済み）
- `data/raw/` — 生データ（不変。変更・削除しない）
- `data/processed/` — 加工済みデータ

## 作業ルール

### 基本方針
- このプロジェクトの docs は卒論作成のための計画・設計ドキュメント
- docs の再構成・統合・分割は随時行ってよい
- 構想段階では粒度を上げすぎず、フラットな構成を維持する
- 具体化が進んだタイミングで必要に応じて分割する

### データ
- `data/raw/` は不変。絶対に変更・削除しない
- データ前処理のスクリプトは再現可能な形で `src/` に置く

### 分析コード
- Python を主言語とする（変更の場合は明示指示が必要）
- 分析の再現性を確保する
- 中間成果物は `data/processed/` に出力する

### コミット
- Conventional Commits に従う
- 1コミット = 1論理ステップ

## 卒論固有の注意

- この卒論の主戦場はデータであり、理論モデルではない
- スコープを常に意識する（詳細は `docs/overview.md` のスコープ節を参照）
- スコープ外: 資本フロー（FDI・ポートフォリオ投資）、市区町村単位、サプライチェーンリスク・地政学リスク、産業構造変化の原因分析（所与として先行研究から引用）
- スコープ内: 所得階層別の消費反応比較（MPC的分析を含む）
- 判断に迷ったら `docs/decision-log.md` に記録する

## スライド作成ルール

ゼミ発表・論文発表向けのスライドを作成する際は、必ず `docs/DESIGN.md` を参照・遵守する。

### DESIGN.md の役割
- スライドのビジュアル・構造・トーン・コンテンツの全ルールを定義する唯一の参照源
- スライド生成・修正・レビューの際は常にこのファイルを読み込んでから作業する

### スライド作成時の手順
1. `docs/DESIGN.md` を読み込む
2. 発表の目的・対象・時間制限をユーザーに確認する（未指定の場合）
3. `docs/DESIGN.md` の「Recommended Slide Flow」に従って構成を提案する
4. ユーザーの承認後にスライドコンテンツを生成する
5. 生成後は `docs/DESIGN.md` の「Final Check」で自己検証する

### スライドの保存場所
- `slides/` ディレクトリに格納する
- ファイル名: `YYYYMMDD-<発表名>.md`（Markdownで構造を記述）
- 例: `slides/20260520-seminar1-proposal.md`

### スライドフォーマット
- Markdown形式でスライド構造を記述する（1スライド = `---` 区切り）
- 各スライドの先頭に `# タイトル` を置く
- ビジュアルの指定はコメント（`<!-- -->` または `> [図]` 記法）で補注する

### 禁止事項
- DESIGN.md を参照せずにスライドを生成しない
- デザインルールに反するスライドを提案しない（華美・過密・散漫）
- ユーザーの承認なくスライド枚数・構成を大幅変更しない

## 主要結果サマリー（スライド・論文執筆の参照用）

### Phase 1: 交易損失（輸入コスト負担増）
- 2022年 5グループ合計: 中心推計35兆円（2015-19正常基準・エネルギー67%・GDP比6.3%）／上限40.7兆円（2020基準）。中心: 2023年28兆円・2024年29兆円（DEC-012）
- エネルギーグループ価格上昇: +203%（2020→2022年）

### Phase 2: 家計帰着
- **貢献の再定義（DEC-015）**: Phase 2a の因果識別は中心目標から外す。exposure-robust shift-share（A-4）＋期間延長テスト（案2）で**単一マクロ事象からのコストプッシュ清浄識別は不可能**と積極的に確認＝**識別限界の方法論的提示という貢献**に転化。実証的背骨は Phase 2b（恒等式）と Phase 1（会計）
- コストプッシュ転嫁係数: β=0.425（p=0.047・メイン仕様・競争輸入財除外・B-4 IC是正後の再生成値＝DEC-021）は「cost-push と整合的な点推定」。ただし**クリーンな two-way FE / FD-Koyck spec では非有意**・期間延長でも救えない（DEC-013）。cluster-entity の p=0.002 は exposure-robust でなく楽観的。「因果的に識別」とは書かない
- プラセボ期は非有意。年次相関コントラストが方向的に支持（pooled プラセボ β=0.540 は無情報・因果断定せず。design-review A-2）
- **Q1-Q5実効インフレ格差（実績CPI使用・恒等式・識別仮定に非依存＝最も頑健）: 2022年+2.14pp、2023年+1.96pp、2024年+2.67pp**（DEC-011 正シェアでの再生成値・旧 +1.42/+0.90/+1.13 は行順依存バグ時代のシェア由来で撤回＝DEC-021）

### Phase 3: シミュレーション・政策評価 ★**定性・例示に降格**（DEC-014・2026-05-31）
- **位置づけ**: IO 価格モデルは cost-push を実績CPI比 ~2倍 overshoot（中間投入経由でサービス等に過剰伝播＝C-4 構造ミスマッチ・β=0.425 でも残る）。政策削減率は B-4 IC是正後に大きく動き IC/Leontief 構築に強く依存。**特定の%・pp 絶対値は結論にしない。incidence accounting（事前会計・行動反応なし＝C-1）かつ例示として appendix 扱い**
- **真に頑健（符号レベル・結論に使える）**: Q1>Q5（逆進的・全ショック年）、energy が最大の寄与カテゴリ、エネ/食料補助は方向として gap を縮める、δ感度（0.4〜1.0）で方向不変
- **例示・参考（重 caveat 付き・headline にしない）**: coherent δ=0.55・β=0.425 で baseline cost-push Q1-Q5 gap 2021/22/23/24 = 0.37/1.05/1.23/1.35pp（β-invariant でないモデル依存値）。エネ補助50%=機械的 gap の約45%（2022 44.7%／2024 40.0%）、複合=約57%。これらは「β に不変だが IC/Leontief 依存・overshoot で上方バイアス」（advisor: β-invariant≠robust）
- IOモデル Koyck RMSE: 10.00pp（δ=0.55・B-4 後の再生成値）。ただし C-2 通り「検証達成」でなく「誤差=demand-pull 残差の分解」として提示。δ=0.55 は推定値でなく calibration（半減期≈10.4ヶ月、RMSE は[0.5,0.7]平坦・厳密最小≈0.60＝C-3）
- G-3（Koyck 未適用）は実験ブランチ f9e9b21 で既に解消済（fresh 再生成=cache 完全一致を確認）。β=1 Leontief=構造的上限、×0.425 は例示的スケーリングで構造パラメータと称さない（C-4）
