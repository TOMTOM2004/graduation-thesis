# 卒業論文プロジェクト — Claude Code ルール

## プロジェクト概要

外的要因による輸入価格ショックが日本の実質所得を海外に流出させる構造を定量化し、財の特性と所得階層の異質性を加味して家計消費への影響を分解し、シミュレーションモデルによる政策評価を行う学部卒業論文。
実証経済学・応用計量経済学に属する構造分析とシミュレーションを組み合わせた研究。

**現在のフェーズ: Phase 1〜3（分析）完了 → 論文執筆 + ゼミ発表スライド作成**

---

## ドキュメント構成

- `docs/` — 卒論の研究計画・設計ドキュメント（INDEX.md がエントリーポイント）
- `docs/DESIGN.md` — スライド作成のビジュアル・構造ルール（後述）
- `src/` — 分析コード（実装済み）
- `data/raw/` — 生データ（不変。変更・削除しない）
- `data/processed/` — 加工済みデータ

## 作業ルール

### 基本方針
- このプロジェクトの docs は卒論作成のための計画・設計ドキュメント
- docs の再構成・統合・分割は随時行ってよい
- 構想段階では粒度を上げすぎず、フラットな構成を維持する
- 具体化が進んだタイミングで必要に応じて分割する

### データ
- `data/raw/` は不変。絶対に変更・削除しない
- データ前処理のスクリプトは再現可能な形で `src/` に置く

### 分析コード
- Python を主言語とする（変更の場合は明示指示が必要）
- 分析の再現性を確保する
- 中間成果物は `data/processed/` に出力する

### コミット
- Conventional Commits に従う
- 1コミット = 1論理ステップ

## 卒論固有の注意

- この卒論の主戦場はデータであり、理論モデルではない
- スコープを常に意識する（詳細は `docs/overview.md` のスコープ節を参照）
- スコープ外: 資本フロー（FDI・ポートフォリオ投資）、市区町村単位、サプライチェーンリスク・地政学リスク、産業構造変化の原因分析（所与として先行研究から引用）
- スコープ内: 所得階層別の消費反応比較（MPC的分析を含む）
- 判断に迷ったら `docs/decision-log.md` に記録する

## スライド作成ルール

ゼミ発表・論文発表向けのスライドを作成する際は、必ず `docs/DESIGN.md` を参照・遵守する。

### DESIGN.md の役割
- スライドのビジュアル・構造・トーン・コンテンツの全ルールを定義する唯一の参照源
- スライド生成・修正・レビューの際は常にこのファイルを読み込んでから作業する

### スライド作成時の手順
1. `docs/DESIGN.md` を読み込む
2. 発表の目的・対象・時間制限をユーザーに確認する（未指定の場合）
3. `docs/DESIGN.md` の「Recommended Slide Flow」に従って構成を提案する
4. ユーザーの承認後にスライドコンテンツを生成する
5. 生成後は `docs/DESIGN.md` の「Final Check」で自己検証する

### スライドの保存場所
- `slides/` ディレクトリに格納する
- ファイル名: `YYYYMMDD-<発表名>.md`（Markdownで構造を記述）
- 例: `slides/20260520-seminar1-proposal.md`

### スライドフォーマット
- Markdown形式でスライド構造を記述する（1スライド = `---` 区切り）
- 各スライドの先頭に `# タイトル` を置く
- ビジュアルの指定はコメント（`<!-- -->` または `> [図]` 記法）で補注する

### 禁止事項
- DESIGN.md を参照せずにスライドを生成しない
- デザインルールに反するスライドを提案しない（華美・過密・散漫）
- ユーザーの承認なくスライド枚数・構成を大幅変更しない

## 主要結果サマリー（スライド・論文執筆の参照用）

### Phase 1: 交易損失（輸入コスト負担増）
- 2022年 5グループ合計: 中心推計35兆円（2015-19正常基準・エネルギー67%・GDP比6.3%）／上限40.7兆円（2020基準）。中心: 2023年28兆円・2024年29兆円（DEC-012）
- エネルギーグループ価格上昇: +203%（2020→2022年）

### Phase 2: 家計帰着
- コストプッシュ転嫁係数: β=0.431（p=0.002）、メイン仕様（競争的輸入財除外）
- プラセボ期（2015-2019）は非有意（p=0.417）→ 識別仮定を支持
- Q1-Q5実効インフレ格差（実績CPI使用）: 2022年+1.42pp、2023年+0.90pp、2024年+1.13pp

### Phase 3: シミュレーション・政策評価
- IOモデル Koyck RMSE: 9.744pp（δ=0.55、目標 < 10.5pp）
- コストプッシュ純分 Q1-Q5格差: 2022年+0.32pp（全ショック年でQ1 > Q5）
- エネルギー補助50%: コストプッシュ起因の逆進性を101.6%解消（2022年）
- 複合介入（エネルギー50%+食料30%）: 格差削減率123.8%
- δ感度（0.4〜1.0）: 定性的方向不変
