# 卒業論文プロジェクト — Claude Code ルール

## プロジェクト概要

コストプッシュインフレ下の日本の家計実消費の実態把握に関する学部卒業論文。
実証経済学・応用計量経済学に属する実態把握重視のデータ分析研究。

---

## ドキュメント構成

- `docs/` — 卒論の研究計画・設計ドキュメント（INDEX.md がエントリーポイント）
- `src/` — 分析コード（今後作成）
- `data/raw/` — 生データ（不変。変更・削除しない）
- `data/processed/` — 加工済みデータ（今後作成）

---

## 作業ルール

### 基本方針
- このプロジェクトの docs は卒論作成のための計画・設計ドキュメント
- docs の再構成・統合・分割は随時行ってよい
- 構想段階では粒度を上げすぎず、フラットな構成を維持する
- 具体化が進んだタイミングで必要に応じて分割する

### データ
- `data/raw/` は不変。絶対に変更・削除しない
- データ前処理のスクリプトは再現可能な形で `src/` に置く

### 分析コード
- Python を主言語とする（変更の場合は明示指示が必要）
- 分析の再現性を確保する
- 中間成果物は `data/processed/` に出力する

### コミット
- Conventional Commits に従う
- 1コミット = 1論理ステップ

---

## 卒論固有の注意

- この卒論の主戦場はデータであり、理論モデルではない
- 「全部盛り」は禁止。スコープを常に意識する
- MPC推定・市区町村単位・因果と予測の同時実施はスコープ外
- 判断に迷ったら `docs/decision-log.md` に記録する
