Problem Setting / 問題意識

日本は46ヶ国中9位の所得流出（対GDP比 3.28%）

輸入価格ショックによる実質所得の海外流出は日本に固有ではない。
しかし日本はその影響の大きさで流出側の上位に位置する。
  • 2022年、世界の多くの国が交易条件の悪化に直面
  • 日本は流出側の上位 — 9位 / 46ヶ国・対GDP比 3.28%
  • 流出を免れたのはエネルギー輸出国（ノルウェー・サウジ・豪・加）

Problem Setting / 問題意識

所得流出の主因はエネルギー輸入依存（R²=0.64）

純エネルギー輸入の度合いは、2022年の交易損失の国間ばらつきの約6割を説明する。
  • エネルギーを輸入に依存する国ほど、大きな所得流出を被った
  • 交易利得を得たのはエネルギー輸出国（ノルウェー等）
  • 日本はエネルギー使用の約9割を純輸入に依存 — 脆弱性の典型例

Problem Setting / 小括

日本の所得流出は偶発でなく構造に根ざす

本研究の問い

エネルギーを中心とする輸入依存という構造の上で、輸入価格ショックがどの経路を通じ・どの規模で・誰の負担として実質所得を流出させているか。

国際比較は、本研究が捉える脆弱性が日本において特に深刻であることを裏づける。次章以降は、この構造を ①所得流出の規模 → ②家計・所得階層への帰着 → ③政策評価 の順で国内データから定量化する。
