# 分析計画

## 全体フロー

```
Phase 1: 因果推論
  ├─ コストプッシュインフレの発生確認
  ├─ カテゴリ別の価格転嫁率・消費感応度の推定
  └─ 地域別の波及度合いの推定
       ↓ 推定パラメータ
Phase 2: シミュレーションモデル構築
  ├─ Phase 1 の推定値をモデルに投入
  └─ モデルの妥当性検証
       ↓ 構築済みモデル
Phase 3: 政策評価
  ├─ 政策パラメータの設定
  └─ 影響のシミュレーション
```

---

## Phase 1: 因果推論

### 前提の確認
コストプッシュインフレが起きていることを実証的に確認する。
- 既に広く認められている事実だが、本論文の文脈で改めてデータで示す
- どのチャネル（エネルギー・食品・輸入物価等）を通じて波及しているかを特定する

### 中心仮説
**コストプッシュインフレの家計消費への波及は、カテゴリと地域によって異質である。**

### 推定する対象
| 対象 | 概要 |
|------|------|
| カテゴリ別価格転嫁率 | 輸入物価上昇が各消費カテゴリの価格にどの程度転嫁されているか |
| カテゴリ別消費感応度 | 各カテゴリで価格上昇に対して消費（名目・数量・構成）がどう反応するか |
| 地域別波及度 | 都道府県間で波及の程度がどう異なるか |

### 未決事項
- [ ] 識別戦略の具体化（research-design.md と連動）
- [ ] 推定手法（DID / IV / shift-share 等）
- [ ] 裁量的支出の操作的定義

## Phase 2: シミュレーションモデル構築

### 設計方針
- Phase 1 で推定したパラメータを入力として使用する
- 実証に裏付けられたモデルとすることで恣意性を排除する

### 未決事項
- [ ] モデルの具体的な仕様
- [ ] GDP支出面（C+I+G+NX）の恒等式をベースにするかどうか
- [ ] モデルの妥当性検証の方法

## Phase 3: 政策評価

### 設計方針
- シミュレーションモデル上で政策パラメータを変化させる
- 「どこに」「どの程度」影響が及ぶかを評価する

### 未決事項
- [ ] どの政策を対象とするか
- [ ] 政策パラメータの設定方法
- [ ] 評価指標

---

## MPC推定について

スコープ外。理由: MPCは所得変動との関係で定義されるため、消費データだけでは推定困難。所得ショック・家計属性・識別の要求が本論文のスコープを超える。
