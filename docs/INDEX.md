輸入価格ショックによる実質所得の海外流出と家計への逆進的帰着 — 会計的定量化・恒等式記述・識別限界の提示

## 一文要約
輸入価格ショックによる実質所得の海外流出を会計的に定量化し（交易損失 中心~35兆円・2022）、その家計帰着の逆進性を実績CPI×支出シェアの恒等式で記述する（Q1-Q5 +2.14pp・実証的背骨）とともに、コストプッシュ効果の因果識別の到達点と限界を方法論的に提示し、統合シミュレーションで政策介入の方向を例示する研究（クレーム階層は DEC-017）。
