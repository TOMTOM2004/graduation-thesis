# 五分位 × 費目曝露 DiD の実現可能性調査（ITEM-021 手順3）

作成: 2026-07-24 ／ ブランチ: worktree-item021-quintile-did ／ スクリプト: `src/analysis/quintile_did.py` ／ 出力: `data/processed/did/`

## 調査目的（ユーザー依頼の3問）

1. DiD は現状の研究結果を覆すか
2. 現状方針と異なる設計により、DEC-013/015 で「不可能」とした識別が改善される可能性はあるか
3. 手法変更（時系列β → DiD）はより信頼性・信憑性を持つか

## 設計

- パネル: CPI中分類対応の **40費目**（家計調査・用途分類と同名一致 36 + 合算・近似 4、放送受信料のみ対応不能で除外）× 五分位 × 暦年 2015–2024（DEC-023）
- 曝露: 費目別輸入含有率 IC_c（`bridge_matrix` の直接＋間接・B-4是正済・競争輸入型国内レオンチェフ）
- (A) 価格伝播 event-study: `Δlog CPI_{c,t} = α_t + β_t·IC_c`（年別クロスセクション、HC1 + IC ラベル permutation 推論）
- (B) シェア triple-diff: `s_{q,c,t}`（Q1 vs Q5）に費目×分位FE・年×分位FE、`IC×年` と `IC×年×Q1`（基準 2021）、費目クラスタSE

## 結果

### (A) 価格伝播（識別改善テスト）

| 年 | β_t (pp/IC) | p_HC1 | p_perm |
|---|---|---|---|
| 2016 | +4.41 | 0.052 | 0.272 |
| 2020 | +4.31 | 0.079 | 0.126 |
| 2021 | +1.48 | 0.651 | 0.692 |
| **2022** | **+0.41** | **0.917** | **0.927** |
| 2023 | +8.71 | 0.063 | **0.038** |
| 2024 | −4.35 | 0.504 | 0.503 |

- **最大ショック年 2022 の β はゼロ**。原因は機械的で、2022年の価格上昇上位3費目（他の光熱 +18.4pp・電気代 +18.3pp・ガス代 +17.0pp）の測定 IC が 0.18/0.025/0.029 と最低水準＝**IO由来 IC がエネルギー小売価格の輸入燃料チャネルを捉えない**（C-4 構造ミスマッチと同型の問題が曝露測度側で再現）。
- エネルギー4費目除外でも β_2022=+4.6 (p_perm=0.14)・β_2023=+5.2 (p_perm=0.097) で、プレ期 2020 の +3.6 と同規模＝プラセボ基準を満たさない。
- 累積 Δlog CPI 2021→2024 on IC: β=+4.8 (p_perm=0.55)。無情報。
- 唯一の有意年 2023（食料チャネルの遅延転嫁と整合）は、ノイジーなプレ期（2016 +4.4）を持つ設計で単年のみ＝因果主張に耐えない。

### (B) シェア triple-diff（行動込み帰着）

- θ_t（IC×年×Q1）: post 期 2022 −0.49 / 2023 −0.45（いずれも p≈0.15、非有意）。**符号は「Q1 が高曝露費目の支出シェアを Q5 対比で削った」**＝価格負担に対する数量削減・代替を示唆（逆進性と整合、覆さない）。
- プレトレンド joint F(6)=1.17, p=0.34 で棄却されないが、**2015 単年 θ=−0.84 (p=0.037)・2020（コロナ年）θ=−0.45 (p=0.053)** と post と同規模の攪乱があり、平行トレンドの説得力は弱い。

## 3問への回答

1. **覆さない。** Q1>Q5 の逆進的曝露・帰着（恒等式＝柱③）と矛盾する結果は皆無。シェア反応の点推定はむしろ「Q1 は高曝露財で数量を削っている」方向で、負担の実在を補強する（ただし非有意）。
2. **改善されない — むしろ独立の設計で識別限界が再確認された。** 時系列β（DEC-013）とは独立なクロスセクション曝露設計（DEC-024 の GPSS 系統）でも、(i) ショック本丸のエネルギーで曝露測度が機能しない、(ii) プレ期プラセボが汚い、(iii) 最大ショック年で β=0、の三重で清浄識別に失敗。**DEC-015 の「識別限界の方法論的提示」という貢献が、2つ目の設計での失敗により強化される**（単一設計の失敗→複数設計で確認された失敗）。
3. **因果推定量としての DiD は現行手法より信頼性が高くない**（自らのプレトレンド・プラセボ基準を満たさず、曝露測度妥当性に致命的問題）。**信頼性が上がるのは提示形式としての DiD**: スライド7 を「曝露×分位×時点の記述的三重コントラスト」として多年度化（2015–2019 プレ期で Q1>Q5 差が安定 → 2022–2025 で持続）すれば、ゼミの DiD 直観に応えつつ過剰主張を避けられる。

## 推奨（Decision log 追記案）

- 五分位 DiD: **回帰係数としては不採用**（本調査の (A)(B) が根拠）。**記述的三重コントラストとしてスライド7 多年度化に統合**。
- 副産物: (A) の「2つ目の設計でも識別失敗」は論文の識別限界節（DEC-015 の貢献）に 1 段落追加できる正の材料。
- 曝露測度の注意: IO 由来 IC はエネルギー小売（電気・ガス）の輸入燃料チャネルを構造的に過小評価する。IC を使う全分析（柱②の曝露説明を含む）でこの限界を明記すること。
