## Phase 1: 所得流出の構造定量化

- ✓ **産業連関表 × 輸入含有率**: 2020年表（約100部門）読み込み・輸入含有率算出スクリプト実装済
- ✓ **BOJ CGPI 連結**: 2020年基準系列 + 2015-2019 連結指数（`cgpilink1.csv`）結合済。識別の時系列カバレッジを確保
- ✓ **5グループ別 輸入コスト負担推計**: 2022年合計 中心35兆円（2015-19正常基準・エネルギー67%）／上限40.7兆円（2020基準）算出済（DEC-012）
- ✓ **先行研究との照合**: 齊藤 2022（GNI比 4.6%）と整合的なオーダー

## Phase 2: 家計帰着分析

- ✓ **CPI × IO bridge**: CPI 中分類 41カテゴリーへの bridge matrix 構築済（`bridge_matrix_mid.py`）
- ✓ **競争的輸入財の識別**: 衣類・履物の中国/競争的アジアサプライヤー比率データ取得済（e-Stat 0003313968 / 0003425296）
- ✓ **パネル OLS 推定**: メイン仕様（競争的輸入財除外）β=0.431, p=0.002 動作確認済
- ✓ **プラセボ検証**: 2015-2019 期非有意（β=0.231, p=0.417）→ 識別仮定 supported
- ✓ **家計調査 × IO 接合**: 五分位別の費目別実効インフレ格差を算出可能
- ✓ **Q1-Q5 実効インフレ格差**: 2022年 +1.42pp、2023年 +0.90pp、2024年 +1.13pp（実績CPI使用）

## Phase 3: シミュレーション・政策評価

- ✓ **IO 価格モデル + マイクロシミュレーション**: 基本骨格実装済
- ✓ **Koyck 動学**: δ=0.55 導入、RMSE 9.744pp（目標 < 10.5pp 達成）
- ✓ **政策シナリオ評価**: エネルギー補助 50%（逆進性 101.6% 解消）、複合介入（エネルギー 50% + 食料 30%、123.8% 解消）算出済
- ✓ **δ 感度分析**: 0.4〜1.0 で定性的方向不変を確認済
