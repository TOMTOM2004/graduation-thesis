# Expected Contribution — 3軸の整理

第1回ゼミ発表（seminar1, 2026-05-20）時点での「期待される貢献」の整理。
スライド `s10b Expected Contribution` の一次ソース。

---

## Axis 1: 学術的貢献（Academic）

### 何を埋めるのか
`docs/overview.md` 「先行研究の3つの空白」より:
- **空白①**: マクロの交易損失規模（齊藤 2022 = GNI比 4.6%）は推計されているが、家計レベル・所得階層別への分解は未実施
- **空白②**: コストプッシュ成分のみを取り出した逆進性の定量化は未実施（従来はデマンドプル混入）
- **空白③**: 欧州型（Amores et al. 2025）の IO×マイクロシミュレーションを日本データで実装した統合モデルは未存在

### 本研究の貢献
- 5グループ別（エネルギー / 木材 / 金属 / 化学 / 食料）の所得流出構造を定量化
- パネル OLS。ショック期 vs プラセボ期の年次相関コントラストが shock-specificity を方向的に支持（pooled プラセボは無情報、cost-push 固有とは断定せず＝整合的どまり。限界は research-design.md「識別の到達点と限界」）
- 競争的輸入財（衣類・履物）の post-hoc ではない事前定義による除外 → β=0.431（p=0.002）
- 家計調査の所得五分位 × 必需品/裁量品 2軸での実効インフレ格差を算出
- 日本データを用いた IO × マイクロシミュレーション統合モデルの構築

## Axis 2: 政策的貢献（Policy）

### 評価対象の政策シナリオ
- エネルギー補助（補助率 50% 等） — 直接的な必需品コスト緩和
- 食料支援（補助率 30% 等） — 低所得層の食料負担軽減
- 複合政策（エネルギー 50% + 食料 30%） — 相互作用を含む

### 期待される成果
- 単体政策の効果と複合政策の相互作用を区別して測定
- 所得階層別の政策効果の異質性を可視化
- 補助金設計の優先順位（エネルギー優先 vs 食料優先 vs 複合）への含意

## Axis 3: モデル成果物（Deliverable）

### モデルの位置づけ
`docs/decision-log.md` DEC-001 より: 「政策シミュレーションは拡張ではなく本論の一部」「モデル自体が主要な成果物」

### モデル機能
- **入力**: 輸入価格変化率（5グループ別）、為替レート、政策パラメータ
- **出力**: 階層別の実質消費変化、GDP消費への集計的影響、政策の分配効果
- **パラメータ可変**: Koyck δ、補助率、財別感応度 等

### 継続資産としての価値
- 卒論提出後も他研究者・政策担当者が利用可能
- 新たな輸入価格ショック・新政策の評価に再利用できる構造
- 研究室の knowledge base としての継続性

## クロージング

3 軸を統合すると、本研究の中核は:

> **「日本独自の所得流出 → 家計分配 → 政策評価」を一気通貫で扱える統合シミュレーションモデルの構築**
