### 主表（10大費目=用途分類ベース。2022年の支出割合はこちら）
- **用途分類 002 用途分類（年間収入五分位階級別）** — statsDataId / statdisp_id = **0002070005**
  - https://www.e-stat.go.jp/stat-search/database?layout=dataset&statdisp_id=0002070005
  - 対象: 二人以上の世帯（2000年〜）・勤労者世帯 / 年次 / **収録 1985〜2025年**（2023・2024・2025 とも収録を実画面で確認）

  - 支出割合は消費支出計に対する比率として金額表から自前算出

## 3. 分類・定義の接続性（2022 → 2023-2025）

- **五分位の定義**: 年間収入五分位階級の定義に改定なし。各年の年収分布で境界値が動くのは定義通り（断絶ではない）。
- **費目分類**: **収支項目分類の2025年1月改定あり**（https://www.stat.go.jp/data/kakei/change2025.html ）。ただし改定は**品目レベルの分割・統合**（例: 「マスク」の分割表章）で、**10大費目レベルには影響なし**。用途分類DB（0002070005）は1985〜2025を単一系列で収録＝10大費目の支出割合は 2022→2025 でそのまま接続可。
- 品目粒度で CPI 対応表と突合する場合のみ、2025年改定の段差リスクに注意（2025年改定DBは1985年まで遡及再編済なので、DB内では接続済）。

## 4. 取得手段

- **DB化済 → e-Stat API（getStatsData, appId 要）で取得可**。statsDataId=0002070005（用途分類・五分位）/ 0004023607（品目分類・五分位）。CSV/JSON/XML。
- 画面からの DB ダウンロード（CSV）、詳細結果表の Excel も併用可。

## 5. ゲート判定

**多年度化: 可。** 2023・2024・2025 の3年とも、2022年と同一の表体系（用途分類×五分位、DB 0002070005）で年次値が取得でき、10大費目レベルの分類断絶なし。

付帯条件（データ可用性の問題ではなく解釈上の注記）:
1. **2025年値はエネルギー補助金の間欠実施（電気・ガス 1-3月/7-9月）を反映**＝「政策込み」注記必須（2025-data-availability.md の既知 caveat）。
2. 品目粒度に降りる場合のみ2025年分類改定の対応表チェックが必要。10大費目の割合分析には不要。
3. 手元 `household_quintile_2015_2024.csv` は2024年止まり → 2025年分は要再取得（DEC-011/021 の行順依存バグ前科があるため正シェア確認を必須に）。
