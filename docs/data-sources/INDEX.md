# データソース INDEX

空洞化（IV候補）指標の長期年次時系列。コストプッシュ比率との時系列回帰で外生的な操作変数 / 説明変数として使用する想定。

## 公的統計

### 海外事業活動基本調査 — 海外生産比率（経済産業省）★IV第一候補
- **指標**: 製造業 海外生産比率（国内全法人ベース = 現地法人売上高 /（現地法人売上高 + 国内法人売上高））
- **粒度**: 全国 × 年次 ×（業種別あり：輸送機械・電気機械・情報通信機械 等）
- **期間**: 概況ベースで1990年代〜最新（2023年度実績 = 第54回まで公表）。2001年以降の変動は大きい（2010年代17〜18% → 2021年度25.8% → 2022年度27.1% → 2023年度27.2%）
- **主要変数**: 海外生産比率（国内全法人ベース／海外進出企業ベース）、現地法人企業数・従業者数・売上高・経常利益・設備投資額の推移
- **アクセス**:
  - 海外生産比率の長期系列は **各回「調査概況」PDF / Excel の図表**に掲載（e-Statの「現地法人の時系列データ」テーブルには企業数・売上高等のみで、海外生産比率そのものは含まれない点に注意）
  - e-Stat 政府統計コード 00550120、API（XML/JSON/CSV）対応、概況はExcel
  - METIトップ: https://www.meti.go.jp/statistics/tyo/kaigaizi/index.html
  - 業種別の長期推移表（参考・要典拠確認）: JFTCキッズ https://www.jftc.or.jp/kids/kids_news/japan/kadai_table.html
- **適合度**: 適合。空洞化IVの第一候補。年次・全国・2001年以降の変動大。ただし海外生産比率の連続系列は各回PDFから手作業抽出が必要（一括CSVが存在しない）
- **制約**: (1) 海外生産比率は連続データセットでなく回ごとの概況図表からの抽出が必要、(2) 国内全法人ベースと海外進出企業ベースで水準が異なる（定義の統一に注意）、(3) 調査対象企業の捕捉率変動・定義改定の段差リスク、(4) 標本調査ベース
- **調査日**: 2026-06-21

### 輸入浸透度（経済産業省 産業活動分析 ほか）★IV第二候補
- **指標**: 製造業 輸入浸透度 = 輸入 /（国内出荷 + 輸入 − 輸出）等。鉱工業出荷指数・輸出入を組み合わせて算定
- **粒度**: 全国 × 年次 / 一部四半期 × 業種別
- **期間**: 鉱工業指数ベースで昭和55年（1980）以降の長期時系列が利用可能
- **主要変数**: 輸入浸透度指数、相対価格、輸入数量指数
- **アクセス**:
  - 産業活動分析「輸出入」: https://www.meti.go.jp/statistics/toppage/report/bunseki/in_ex.html
  - 鉱工業指数の長期時系列: https://www.meti.go.jp/statistics/toppage/jikeiretsu/index.html
  - 学術用の整備済み系列は **RIETI JIPデータベース2018**（産業連関表・供給使用表 + 相手国別輸入額1994-2018）から構築可能。100部門、1994-2015、xlsx
- **適合度**: 適合（IV第二候補）。年次・業種別・長期。ただし単一の「輸入浸透度」連続CSVは公式に少なく、出荷・輸出入から自前算定するか JIP から構築する必要あり
- **制約**: (1) 公式に完成形の輸入浸透度時系列が少なく算定式・分母定義に複数流儀、(2) 指数（基準年）と金額ベースの混在に注意、(3) JIPは2015年で終了（最新年が取れない）
- **調査日**: 2026-06-21

### 労働力調査 長期時系列 — 製造業就業者シェア（総務省）
- **指標**: 製造業就業者数 / 全産業就業者数
- **粒度**: 全国 × 月次 + 年平均 × 産業別
- **期間**: 長期時系列（年平均は概ね1953年以降、産業別は産業分類改定で接続注意。第12・13回改定分類は2007年〜）
- **主要変数**: 主な産業別就業者数（製造業含む）
- **アクセス**: e-Stat 政府統計コード 00200531、長期時系列データ https://www.stat.go.jp/data/roudou/longtime/03roudou.html 、Excel / API
- **適合度**: 適合（空洞化の代理指標）。年次・全国。ただし「海外移転」と「サービス化」を分離できない（脱工業化全般を拾う）ため IV としては内生性懸念あり → 補助指標向き
- **制約**: 産業分類改定（2007年）で系列に段差、就業者シェア低下は海外移転以外の要因も含む
- **調査日**: 2026-06-21

### 国民経済計算（SNA）— 製造業付加価値シェア（内閣府）
- **指標**: 製造業 名目付加価値 / 名目GDP（経済活動別国内総生産）
- **粒度**: 全国 × 年次（四半期の経済活動別もあり）× 産業別
- **期間**: 年次推計の経済活動別系列。基準改定（93SNA→2008SNA、基準年改定）で長期接続に注意。参考過去20年で製造業GDPシェアは約4%pt低下
- **主要変数**: 経済活動別国内総生産（名目・実質）、雇用者数
- **アクセス**: 内閣府ESRI https://www.esri.cao.go.jp/jp/sna/menu.html 、e-Stat 政府統計コード 00100409、CSV
- **適合度**: 適合（製造業付加価値シェア）。年次・全国。就業者シェア同様、海外移転以外の構造変化も含むため補助指標向き
- **制約**: 基準改定で接続段差（接続表で調整要）、付加価値シェア低下は一人当たり付加価値上昇とも併存し空洞化と単純対応しない
- **調査日**: 2026-06-21

### 家計調査 品目分類 年間収入五分位階級別 費目別支出（総務省・二人以上の世帯）
- **粒度**: 全国 × 年次（月次表も別途あり）× 品目分類 × 年収五分位（平均＋Q1〜Q5）
- **期間**: DB「品目分類（2025年改定）（年間収入五分位階級：金額）」で 1985—2025。**2023・2024・2025 いずれも収録済**（2025年報は 2026-02-06 公表）
- **主要変数**: 1世帯当たり品目別年間支出金額（五分位別）。用途分類の五分位・十分位表（収支）も別系列で存在
- **アクセス**: e-Stat DB（statdisp_id=0004023607 / stat_infid=000040409548）API・CSV／詳細結果表 年次ファイル（tclass=000000330002, cycle=7）
- **適合度**: Phase 2 の五分位別消費ウェイト更新（`household_quintile_2015_2024.csv` の2025年延長）に適合。旧分類系列: 2020年改定DB・平成27年改定DB（statdisp_id=0003125170）あり
- **制約**: (1) **品目分類2025年改定**あり — 2025年改定DBは1985年まで遡及収録だが、既存CPI品目対応表との突合に段差リスク（2025-data-availability.md の既知caveat）。(2) 2025年値はエネルギー補助金の間欠実施（1-3月・7-9月）を反映＝「政策込み」注記必須
- **調査日**: 2026-07-24

## IV / 時系列回帰での使い分けメモ
- **外生性が相対的に強い順**: 海外生産比率 > 輸入浸透度 > 製造業就業者シェア ≈ 製造業付加価値シェア
- 就業者シェア・付加価値シェアは「脱工業化全般（サービス化含む）」を拾うため、空洞化（海外移転）の純粋なIVとしては弱い → コントロール / 頑健性チェック向き
- 第一候補（海外生産比率・輸入浸透度）は公式の一括CSVが乏しく、概況PDF抽出 / JIPからの自前構築が必要。これが最大の実装コスト
- いずれも**年次**であり、コストプッシュ比率の時系列が月次/四半期なら年次集約 or 年次回帰に揃える必要あり
