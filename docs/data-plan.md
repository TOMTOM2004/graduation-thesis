## オルタナティブデータの位置づけ

**使用すること自体が目的ではない。** よりリアルタイムの消費動向をシミュレーションモデルに投入するための手段。

> **TODO**: 研究質問が確定した段階で、使用の要否・具体的な用途を決定する。

### 使い方の構想
- リアルタイムの消費動向データとして、シミュレーションの入力精度を高める
- 公的統計のタイムラグを補う高頻度データとして活用
- **水準を当てるより、変化率を追う方が安全な可能性が高い**

### 代表性の偏り（最大の懸念）
- 東京と地方でクレジットカード利用率が異なる
- 都市部と地方で商品構成が異なる
- 消費水準が地域により異なる
- 決済データは経済全体ではなく一部の決済行動にすぎない可能性

→ そのまま「真の消費」として扱わず、**何をどの程度映しているかを検討する必要がある**

### 補正の注意点
- 一定倍率を掛けるだけでは危険
- 地域・時点・カテゴリによってズレ方は異なる
- 市区町村単位は扱わない

---

## 公的統計の限界

- タイムラグがある
- 粒度が粗い
- 改定が入る
- 直近の変化を把握しにくい

## 変数（候補）

### アウトカム変数

| 変数名 | 経済学上の概念 | 定義 | 備考 |
|--------|---------------|------|------|
| 名目消費支出 | 名目消費 | 家計が実際に支出した金額 | |
| 実質消費 | 実質消費 | 名目消費を物価で除した値 | deflator の選定が未決 |
| 消費数量指数 | 消費数量 | 物理的な購入量の変化 | データの利用可能性要確認 |
| 消費構成比 | 消費構成 | カテゴリ別支出シェア | |
| カテゴリ別消費感応度 | 価格弾力性 | 物価変動に対する消費反応 | Phase 1 の主要推定対象 |
| 地域別波及度 | 地域間異質性 | 都道府県ごとの波及度合い | Phase 1 の主要推定対象 |

> 注: 「実消費」「裁量的支出」等の曖昧な用語は使用しない。上記の具体的概念で記述する。
