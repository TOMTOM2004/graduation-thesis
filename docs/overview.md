# 研究概要

## 中心テーマ

**コストプッシュインフレは日本の家計消費をどのような構造で圧迫しているか。また、その構造に基づく政策介入はどこにどのような効果をもたらすか。**

---

## 研究質問

### 主問
コストプッシュインフレは日本の家計消費をどのような構造で圧迫しているか。また、その構造に基づく政策介入はどこにどのような効果をもたらすか。

### 副問1（実証）
コストプッシュインフレの家計消費への波及は、カテゴリ別・地域別にどのように異質か。

### 副問2（モデル構築）
副問1で得た波及構造を、シミュレーションモデルとしてどのように表現できるか。

### 副問3（政策評価）
そのモデル上で政策介入を行った場合、影響はどこにどの程度及ぶか。

---

## 論文の構造

```
副問1（実証）
  → カテゴリ別・地域別の価格転嫁率、消費の感応度を推定
  → 推定値を副問2のモデルに投入

副問2（モデル構築）
  → 副問1の推定値で構造化されたシミュレーションモデルを構築
  → 実証に裏付けられたモデルとして恣意性を排除

副問3（政策評価）
  → モデル上で政策パラメータを変化させて影響を評価
```

各副問が独立した貢献を持つ（実証的知見 / モデル構築 / 政策含意）。

---

## スコープ

### 学術的分類
実証経済学・応用計量経済学に属する因果推論とシミュレーションを組み合わせた研究。

### 粒度
- **主戦場**: 都道府県 × 月次 × カテゴリ別
- **スコープ外**: 市区町村単位、MPC推定、因果と予測の同時実施

---

## 一文要約

コストプッシュインフレ下の日本の家計消費への波及構造を因果推論で実証し、その推定結果に基づくシミュレーションモデルを構築して政策効果を評価する研究。
