# 意思決定ログ

## 2026-04 構想段階

### DEC-001: 研究の主役は「実態把握と実証」
- **決定**: 因果推論・予測・政策シミュレーションを同時に主役にせず、実態把握と実証分析を本論の中心とする
- **理由**: 学部卒論のサイズで全部盛りは崩壊する
- **帰結**: 政策シミュレーション・将来予測は拡張扱い

### DEC-002: オルタナティブデータは補助線
- **決定**: 主役ではなく、実態把握を補完する手段として位置づける
- **理由**: 使えなくても研究が成立する設計にすべき
- **帰結**: 公的統計が主たるデータソース

### DEC-003: MPC推定はスコープ外
- **決定**: 限界消費性向の推定は卒論の核から外す
- **理由**: 所得データ・家計属性・識別の要求が大きすぎる
- **帰結**: カテゴリ別感応度・地域別反応・裁量的支出の削減率を見る

### DEC-004: 粒度は都道府県×月次×カテゴリ
- **決定**: 市区町村単位は扱わない
- **理由**: データ安定性・公的統計との接続の観点から危険
- **帰結**: 都道府県単位で十分な知見を得ることを目指す
