# 意思決定ログ

## 2026-04 構想段階

### DEC-001: 研究の構造は積み上げ型3段階
- **決定**: 因果推論（Phase 1）→ シミュレーションモデル構築（Phase 2）→ 政策評価（Phase 3）の積み上げ型設計とする
- **理由**: 各Phaseが独立した貢献を持ち、段階的に積み上げられる。Phase 1が完成すれば論文の価値が残るリスク分散設計
- **帰結**: 政策シミュレーションは拡張ではなく本論の一部

### DEC-002: オルタナティブデータは補助線
- **決定**: 主役ではなく、リアルタイム消費動向をシミュレーションに投入するための手段として位置づける
- **理由**: 使えなくても研究が成立する設計にすべき。使用目的はシミュレーションの入力精度向上
- **帰結**: 公的統計が主たるデータソース。使用の要否は研究質問確定後に判断

### DEC-003: MPC推定はスコープ外
- **決定**: 限界消費性向の推定は卒論の核から外す
- **理由**: 所得データ・家計属性・識別の要求が大きすぎる
- **帰結**: カテゴリ別消費感応度・地域別波及度を見る

### DEC-004: 粒度は都道府県×月次×カテゴリ
- **決定**: 市区町村単位は扱わない
- **理由**: データ安定性・公的統計との接続の観点から危険
- **帰結**: 都道府県単位で十分な知見を得ることを目指す

### DEC-005: 用語の厳密化
- **決定**: 「実消費」「実態把握」「モデル」等の曖昧な用語を排し、正確な経済学用語を使用する
- **理由**: 用語の曖昧さが研究設計のロジック上の矛盾を生んでいた
- **帰結**: 実消費 → 実質消費/消費数量/消費構成等の具体概念、実態把握 → 因果推論、モデル → シミュレーションモデル

### DEC-006: レベルは落とさない
- **決定**: 学部卒論だからという理由でスコープやレベルを落とさない
- **理由**: 経済学部での学びの集大成として本気で取り組む。修士レベルの作業量でも構わない
- **帰結**: スコープ調整が必要な場合は「段階的に積み上げる構成」「リスクを設計で吸収する」方向で対応する

### DEC-007: 案A→案Bへの方針転換
- **決定**: 研究のスコープを「家計消費チャネル」（案A）から「外的要因による所得流出の構造」（案B）に転換する
- **理由**: 矛盾点1の検討を通じて、問題意識の核心が「コストプッシュの原因が外国にあり、消費者のコスト負担が国内に還流せず海外に流出する構造」にあることが明確化。消費チャネルだけでは構造的問題の一側面しか捉えられない
- **帰結**: Phase 1の因果推論設計を全面的に再設計。データソース・識別戦略・理論的フレームワークを変更。案Aは `docs/archive/plan-a-design.md` に保存し、案Bが不可能と判明した場合のフォールバックとする
- **参考**: DEC-004（都道府県粒度）はこの決定により無効化される可能性がある

### DEC-009: 分析期間の確定（設計→実装の調整）
- **決定**: 主分析期間を 2021-2024、プラセボ期間を 2015-2019 とする
- **理由**: 当初設計（DEC-008）では「主分析 2023-2025」としていたが、2つの制約により変更。①BOJ CGPI 2020年基準系列は 2020/01 以降しか存在せず、2015-2019 は連結指数（cgpilink1.csv）で補完する必要がある。② 2025年データはCPI・CGPIともに年途中のため年次平均として使えない。結果として 2021-2024 がショック期の識別に最も適した期間（ウクライナショック 2022 年の△P=+47pp が最大識別力）
- **帰結**: 2015-2019 を「非ショック期プラセボ」として使用。β=0.231、p=0.417 で非有意 → ショック期の結果がショック特有であることを確認（DEC-008 の識別仮定を支持）

### DEC-010: 競争的輸入財（衣料・履物類）の除外基準
- **決定**: CPI 中分類「衣料」（0083）と「履物類」（0098）を Shift-Share 回帰のメイン仕様から除外し、感度分析仕様③として独立して扱う
- **理由**: 両カテゴリーは IO2020 表由来の輸入含有率が衣料 IC=0.876・履物 IC=0.911 と最高水準にある一方、実際の価格転嫁が他の高 IC カテゴリーに比べて著しく低い外れ値。
  - **サプライヤー構造（財務省貿易統計 e-Stat 実データ、2016-2024）**:
    - 中国単体シェア: 衣類 46–64%（平均55%）・履物 41–55%（平均47%）、低下傾向
    - 競争的アジアサプライヤー合計（中国・ベトナム・バングラデシュ・カンボジア・ミャンマー）: 衣類 **81–84%** で安定（2016–2024 を通じほぼ不変）
    - データ: `data/processed/trade-stats/china_import_share_apparel.csv`
  - **価格デカップリングのメカニズム**: これらサプライヤーの価格は生産コスト・労働コスト・為替競争力で決まり、BOJ CGPI 集計輸入物価指数（エネルギー・金属・化学主導）と独立して動く。IO 表が表す平均的な輸入コスト伝播とは整合しない
- **識別への含意**: 除外で β: 0.194 → 0.431（p: 0.176 → 0.002）へ改善。「BOJ CGPI と価格連動している財」に限定したコストプッシュ効果の推定として解釈する
- **帰結**: `bridge_matrix_mid.py` の `is_competitive_import` フラグで管理。除外は post-hoc ではなく「モデルの前提（輸入コスト伝播）が成立する財に限定」という事前定義として論文に記述する

### DEC-008: 案Bの研究質問・スコープ確定
- **決定**: 案Bの研究質問、分析の軸、スコープを確定（詳細は `docs/overview.md` に反映済み）
- **主問**: 輸入価格ショック → 実質所得の海外流出構造 + 家計消費への影響 + 政策効果
- **副問1**: 5グループ別（エネルギー・金属・化学・食料・木材）の所得流出定量化
- **副問2**: 財の分類（必需品 vs 裁量品）× 所得階層の2軸で家計消費への異質な影響を分解。コストプッシュ vs デマンドプルの識別を含む
- **副問3**: シミュレーションモデル構築（モデル自体が主要成果物）+ 政策シナリオの段階的評価
- **スコープ変更**:
  - 所得流出チャネル: 輸入超過1本に統合（デジタル赤字含む）。産業構造変化は背景として先行研究から引用
  - MPC的分析（所得階層別消費反応比較）: スコープ外→スコープ内に変更（DEC-003を更新）
  - 資本フロー（FDI・ポートフォリオ投資）: スコープ外（金融分野として別途）
  - 粒度: セクター別×財の特性別（DEC-004の都道府県粒度から変更）
- **分析期間（暫定）**: ベースライン2015-2019、分析対象2023-2025。コロナ期（2020-2022）は慎重に扱う
- **インフレ識別**: 輸入含有率の差異を利用してコストプッシュをデマンドプルから識別
- **理由**: 先行研究69件の棚卸しを経て、空白領域（交易損失の家計帰着・所得階層別分解・統合シミュレーション）を独自貢献として位置づけた
- **帰結**: 次のステップは副問ごとの具体的な分析設計（データ・推定手法の確定）
