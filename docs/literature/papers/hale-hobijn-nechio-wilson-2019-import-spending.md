## Summary
米国の個人消費支出（PCE）に占める輸入含有量を、IO表を用いて直接輸入と間接輸入（中間財経由）の両方を含めて推計。消費者が直接購入する輸入品だけでなく、国内生産品に含まれる輸入中間財のコストも考慮した包括的な輸入依存度を測定。

## Methodology
- BEAのIO表を用いたPCEの輸入含有量分解
- 直接輸入（消費者が直接購入する輸入品）と間接輸入（国内品の中間投入に含まれる輸入）を分離
- 品目別・国別の輸入含有量を算出

## Key Findings
- 米国消費者支出の1ドルあたり約11セントが輸入コストを反映
- 輸入品への直接支出のうち約半分は国内の流通・サービス付加価値
- 総輸入含有量は過去15年間でほぼ一定
- 中国からの輸入シェアは増加、日本からのシェアは減少

## Relevance to This Thesis
- 本研究の方法論的示唆: 日本版の「消費の輸入含有量」分析の参考モデル
- 案Bの「所得流出が家計消費にどう影響するか」を測定する際の直接的な先行研究
- Bussière et al. (2013, P061)の需要カテゴリ別輸入集約度と補完的
- 品目別の輸入依存度の異質性は、所得層間の影響格差分析に応用可能

## Limitations / Notes
- FRBSFのEconomic Letter（短報）であり、フルペーパーではない
- 米国のデータに基づくが、手法は日本のIO表にも適用可能
- 価格変動の影響は直接扱っていない（数量ベースの分解）
