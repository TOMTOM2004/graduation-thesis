## Summary
米国の所得層別に輸入物価インフレを推定。Nested CESモデルを用いて、低所得層が高所得層より高い輸入物価インフレを経験していることを示した。

## Methodology
- Nested CES需要モデル
- 所得層別の「ホーム貿易シェア」構築
- データ: 米国の人口統計別支出データ + 貿易データ (1996-2018)

## Key Findings
- 低所得層は高所得層より高い輸入物価インフレを経験（1998-2014）
- 全所得層で輸入が全体のインフレを抑制
- 人口統計属性（年齢・人種・学歴・都市部/非都市部）でも差異

## Relevance to This Thesis
- **輸入物価の分配効果**: コストプッシュの主要経路である輸入物価が所得層別に異質な影響を持つことの先行研究
- 手法面ではNested CESアプローチの参考

## Limitations / Notes
- 米国データ。日本は輸入構成が異なる（食料・エネルギーの比率が高い）
