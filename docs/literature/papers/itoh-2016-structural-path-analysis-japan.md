## Summary
地域間社会会計行列（Interregional SAM）を日本で構築し、構造的経路分析（SPA）により経済波及メカニズムを解明した研究。制度部門（家計・企業・地方政府・貯蓄/投資）を詳細に区分したISAMを用いて、地方政府支出が地域所得に与える波及効果の経路とその漏出構造を明らかにした。

## Methodology
- **手法**: 構造的経路分析（Structural Path Analysis, SPA）— 構造分解分析（SDA）の一手法
- **データ**: 日本の地域間社会会計行列（ISAM）。遠隔地域とその他日本（ROJ）の2地域モデル
- **粒度**: 制度部門（家計・企業・地方政府・貯蓄投資）×2地域

## Key Findings
- 地方政府支出の地域所得への波及経路は、遠隔地域とROJで大きく異なる
- 遠隔地域の資金は財産所得を通じてROJに漏出する構造が存在
- SAM乗数の経路分解により、直接効果・経路効果・全体効果を識別可能
- 制度部門間の資金循環経路が地域間格差の一因

## Relevance to This Thesis
- 案Bの「外的要因による所得流出構造」の分析に、制度部門間の資金フロー追跡手法として参考になる
- SAM/SPA は産業連関分析の拡張であり、所得分配・移転を含む包括的な波及分析が可能
- 地域間の所得漏出メカニズムの記述は、本研究のエネルギー輸入による所得流出の議論と構造的に類似

## Limitations / Notes
- 2地域モデルのため地域異質性の詳細な分析には限界
- 静学モデルであり、時系列的な構造変化は捉えられない
- データは2005年前後の日本経済に基づく
