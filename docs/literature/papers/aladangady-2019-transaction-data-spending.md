## Summary
クレジットカード取引データから、リアルタイム・高頻度・地理別の消費支出指標を構築する方法論を提示。FRBの公式プロジェクトとして、民間取引データを経済統計に変換する枠組みを開発。

## Methodology
- First Data社のクレジットカード取引データ（承認額・日付・加盟店住所・MCC）
- 月次消費支出推定値の構築
- 地理別（州・郡レベル）分解

## Key Findings
- 月次消費支出推定値はリアルタイムモニタリングに有効
- 政府シャットダウン（2019年）でCensusデータが遅延した際に特に価値を発揮
- 地理的に全取引がジオロケーション付きで、地域分析が可能

## Relevance to This Thesis
- **オルタナティブデータの方法論的基盤**: 取引データ→経済統計への変換手法の先行研究
- 地理別分解が可能な点は、本研究の都道府県×カテゴリ分析と整合的
- JCB消費NOWなど日本の決済データの活用方法の設計に参考になる

## Limitations / Notes
- 米国データ。日本の決済環境（キャッシュレス比率・クレジットカード普及率）との差異に注意
