## Summary
異質的エージェントNKモデル（HANK）を構築し、金融政策から家計消費への伝達メカニズムを再検討。代表的エージェントモデル（RANK）とは質的に異なる伝達経路を示した。

## Methodology
- HANKモデル: 所得リスク + 流動性の異なる複数資産
- 現実的な資産分布・MPCの分布を再現
- 金利変化の消費への影響を直接効果/間接効果に分解

## Key Findings
- 金利引下げの消費への影響は、間接効果（一般均衡を通じた労働需要増）が直接効果（異時点間代替）を大きく上回る
- RANKモデルとの対比で、家計異質性がマクロ経済動学を質的に変える
- 財政反応が金融政策の効果の大きさを左右する

## Relevance to This Thesis
- **Phase 2の理論的背景**: 家計異質性がマクロ経済の動学を変えるという理論的根拠
- 直接効果 vs 間接効果の分解はシミュレーションモデルの設計思想に影響
- ただし本研究は実証ベースのシミュレーションを志向するため、HANK自体を実装するわけではない

## Limitations / Notes
- 理論モデル。本研究はHANKの知見（異質性が重要）を実証パラメータで裏付ける方向
