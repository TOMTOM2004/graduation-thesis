## Summary
グローバル生産ネットワークがGDPの国際共変動に果たす役割を、ショック伝播とショック相関の加法的分解で定量化した研究（G7、1978-2007年）。

## Methodology
- 多部門・多国間の一般均衡モデル
- GDP共変動をショック伝播成分とショック相関成分に加法分解
- データ: G7諸国、1978-2007年
- 世界産業連関表を用いたネットワーク構造のキャリブレーション
- 構造弾力性の推定範囲を考慮した分析

## Key Findings
- 生産ネットワークを通じたショック伝播は定量的に重要だが、観察される共変動の少数部分にとどまる
- 生産ネットワーク内での相関ショックへの同時的反応が、資本蓄積を通じた時間的伝播よりも共変動の説明に有効
- ネットワーク構造が国際ショック波及の増幅・減衰を決定

## Relevance to This Thesis
- **生産ネットワークを通じたコストショック伝播の理論的基盤**: 本研究が扱う輸入コストショック→国内消費者物価の波及経路を、ネットワーク構造から理解する枠組みを提供
- Rubbo (2023, P025)のネットワーク×フィリップス曲線と補完的
- 日本が生産ネットワークの中でどの程度外的ショックに曝露されるかの理論的根拠

## Limitations / Notes
- マクロ的な共変動分析が主で、家計レベルの分配効果は扱わない
- G7対象で日本を含むが、日本固有の詳細分析ではない
- 本研究のミクロ的な家計消費分析とはスケールが異なるが、背景理解として有用
