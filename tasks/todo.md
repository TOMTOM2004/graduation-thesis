## A. ロジック上の問題（甘い部分）

### A-1. 「実態把握」と「因果推論」の混在
- [ ] 研究質問「どの程度下押ししたのか」は因果的な問いだが、主目的は「実態把握」と書いている。記述研究なのか因果推論なのか、本論の性格を一つに決める
- 「実態把握」なら「実消費はどう変化したか」で止まる。「下押し」と言った瞬間に反事実（コストプッシュがなかったら）が必要になる

### A-2. 識別戦略が発想レベルで止まっている
- [ ] 「事前のさらされ方の差を利用する」は方向性だけで、具体的な設計がない。以下を決める必要がある:
  - 「ショック」とは何か（原油？輸入物価指数？円安？）
  - 「さらされ方」とは何か（エネルギー支出比率？産業構成？）
  - どのバリエーション（地域間差分？時系列変動？）を使うか
  - 具体的な手法（Shift-Share / Bartik / DID / パネル固定効果 等）
- これが決まらないと研究の骨格が立たない

### A-3. 反事実・比較対象の不在
- [ ] 「下押しした」と言うためには「何と比べて」が必要。比較の枠組みを決める
  - コストプッシュ前 vs 後（時系列比較）
  - さらされ方が大きい地域 vs 小さい地域（横断面比較）
  - 両方を組み合わせた DID 的枠組み
  - いずれにせよ、比較対象を明示する

### A-4. 「コストプッシュインフレ」の定義が曖昧
- [ ] 何がコストプッシュで何がそうでないかの境界を定義する
  - エネルギー価格のみ？食料品も含む？円安による輸入物価全般？
  - デマンドプル要因との切り分けはどうするか
  - 定義が曖昧だと識別戦略もアウトカムも定まらない

### A-5. 「実消費」の操作的定義が未確定
- [ ] 「名目消費を物価で除す」と書いてあるが、どの物価で除すかで結果が大きく変わる
  - 全国CPI？地域別CPI？カテゴリ別物価指数？
  - 地域別CPIは県庁所在地のみの可能性が高い → 県全体の代表性は？
  - この選択は研究の根幹に関わるので早期に決める

### A-6. 理論的フレームワークの不在
- [ ] 実証研究でも「なぜカテゴリや地域で反応が異なるのか」の理論的説明が必要
  - 必需品 vs 裁量品で価格弾力性が異なる、という経済理論
  - エンゲル係数が高い地域ほど影響が大きい、等の仮説
  - 理論がないと「結果が出ても解釈できない」状態になる

### A-7. 先行研究への言及がゼロ
- [ ] 既存研究のレビューが完全に欠落している。以下を調べる:
  - コストプッシュインフレと家計消費に関する先行研究
  - 日本の家計消費の実態把握に関する既存分析
  - オルタナティブデータを用いた消費分析の先行研究
  - 自分の研究が何を「新しく」やるのかを位置づける
