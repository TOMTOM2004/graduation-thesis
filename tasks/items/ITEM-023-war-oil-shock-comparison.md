## 背景

既存の Känzig 原油供給ニュース LP に加え、ロシア・ウクライナ戦争に限定した
外部ニュースショックに対する Q1−Q5 固定バスケット生活費格差の一時的応答を検討する。
両分析は係数を掛け算せず、別推定・共通尺度比較・共同回帰の感度分析として接続する。

## 承認済み方針

1. 侵攻後ダミー単独を因果ショックとして使わない。
2. 公開され、外部で固定された戦争ニュース系列を優先する。
3. 月次化後の有効標本が不足する場合、既存 LP を無理に適用しない。
4. 「戦争全体の総効果」と「限界的な戦争ニュースショックの応答」を区別する。
5. 原油・戦争の歴史寄与率は重複し得るため、機械的に加算しない。

## 実装チェックリスト

- [x] Tong / Aizenman / Caldara–Iacoviello 系列の公開性・期間・再現性を確認する
- [x] 月次化後の非ゼロ月、有効標本、原油ショックとの重なりをゲート判定する
- [x] 比較尺度・推論・停止条件をテストで固定する
- [x] データゲート通過・因果ゲート不通過を分離し、探索的LPを実装する
- [x] 原油のみ／戦争のみ／共同推定の結果を比較する
- [x] 既存のウクライナ小麦 ITS のクレーム上限を再判定する
- [x] 結論・貢献③・識別不能という結論への影響を記録する

## 停止条件

- 外部ショック系列を再現可能に取得できない
- 月次固定バスケット格差に対し、ラグ・horizonを含む推定の有効標本が不足する
- 戦争ニュース系列が単なる事後ダミーまたは結果変数に反応する内生的な指数に留まる

停止条件に該当した場合は、因果 LP を実装せず、記述的イベント分析または
「外部で識別された商品価格反応 × 固定バスケット」の会計シナリオへ降格する。

## 完了判定

- データゲート PASS、因果ゲート FAIL。
- 戦争ニュースは食料・光熱へ広く反応するが、Q1−Q5格差は共同推論を通過しない。
- 貢献③は原油供給ニュースに限定し、戦争比較は探索的な反証分析とする（DEC-027）。
